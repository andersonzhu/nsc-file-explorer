Open an NSC enrollment file

      
Drop a National Student Clearinghouse enrollment reporting file anywhere on this page, or choose one. Fixed-width (1250-character) and tab-delimited files both work. The explorer reads the header and trailer, splits every D1 student record into its fields, and checks each one against NSC’s file specifications, so you can find, fix and save problems before you submit.

      
Files are read inside this browser tab. Nothing is uploaded.

Record layouts
A layout lists where each field starts and how many characters it takes. The built-in D1 layout comes from NSC’s Compliance Central file specifications. Add your own for older files or any other fixed-width report.

      
    

    

    

      Share layouts you’ve made
      

        
Layouts you make are saved in this browser only. Copy the export and send it to a colleague, who pastes it below and chooses Import. To build layouts into this file for everyone, paste the export between the office-layouts script tags near the top of the HTML file.
